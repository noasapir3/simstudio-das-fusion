# SimStudio — Release Notes

## Latest version

Changes in this release:

- All roads normalised to a single one-way lane.
- Added per-vehicle visual controls for:
  - Current speed
  - Minimum speed
  - Average speed
  - Maximum speed
  - Maximum acceleration
  - Maximum deceleration
  - Minimum / maximum time between speed changes
- Removed Cruise probability and Accel response from the UI.
- Each vehicle has a randomised but realistic speed profile with periodic speed changes and cruise periods.
- Randomize realistic profile button retained.
- Sensor error formulas documented in docs/SENSOR_ERROR_FORMULAS.md.
